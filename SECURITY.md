# Security

**This project is not a sandbox.** A benchmarked agent can use the invoking account's file, environment, credential, and network permissions. Run it under a dedicated unprivileged account or isolated container/VM with only intended files and credentials. Loopback-only target URL validation is not network isolation.

Do not put real secrets in issues, pull requests, logs, or transcripts. Report suspected vulnerabilities privately to Juan C. Ruiz at [JuanCrg90@gmail.com](mailto:JuanCrg90@gmail.com).
